    The step machine¶

    The sans-IO core: a Session hands out jobs and a program performs them. For a program that is its own driver.

    Names: Answer, Ending, Hook, Job, Next, RunCall, SampleEnd, Session

    Answer¶

    What the driver answers a Job with. Session.answer accepts one only while the job it answers is out; any other raises WrongAnswer.

    Session¶

    class Session

    One session: its tree, cursors, scratchpad, and every cursor's step. It does no IO of its own: a program asks it for each cursor's next Job and gives back an Answer.

    A call that changes the session hands its records to the store (when there is one) before it returns, so a program never saves. Every call takes the session's one lock, so a session may be shared across threads. A closed session raises Closed.

    Session.create¶

    @staticmethod
def create(
    config: Config,
    system: str,
    now: int,
    directory: str | PathLike[str] | None = None,
) -> Session

    A new session with a Config root, a System node, and cursor 0 on it. In directory (created if missing) when given, else in memory.

    Session.load¶

    @staticmethod
def load(directory: str | PathLike[str]) -> Session

    Open the session in directory, taking its lease. Every cursor loads with auto-step off, woken (load is a wake).

    Session.read¶

    @staticmethod
def read(directory: str | PathLike[str]) -> Session

    The session in directory as a copy in memory, as of its last sync, taking no lease and writing nothing (D18 section 7). It accepts changes and never saves them.

    Session.fork¶

    def fork(self, node: int, now: int, directory: str | PathLike[str] | None = None) -> Session

    A new session holding a copy of walk(node) (D18 section 6): node i of the copy is node i of the walk, with cursor 0 on its tip. In directory (created if missing) when given, else in memory, written with one sync. NoSuchNode if node is absent.

    Session.close¶

    def close(self) -> None

    Drop the store and release the lease without writing what is not yet synced, as a crash would. Every later call raises Closed. A second close is Closed too.

    Session.tree¶

    property tree: Tree

    The session's nodes.

    Session.input¶

    def input(self, cursor: int, by: Author, text: str) -> int

    Add an Input item for cursor, written by the author, and wake the cursor. Returns the item's id. NoSuchCursor or CursorClosed if the cursor is not open.

    Session.step¶

    def step(self, cursor: int) -> None

    Run one step of cursor whether or not auto-step is on, and leave auto-step as it is. Busy if a step is already running.

    Session.go_to¶

    def go_to(self, cursor: int, to: int, client: str, now: int) -> bool

    Move cursor to node to for the frontend named client, turn auto-step off and wake the cursor. On a busy cursor the step is aborted and the move applies when it rests. Returns whether the driver must cancel the effect in flight. NoSuchNode if to is absent.

    Session.set_auto¶

    def set_auto(self, cursor: int, on: bool) -> None

    Turn auto-step on or off for cursor; on wakes it.

    Session.abort¶

    def abort(self, cursor: int) -> bool

    Stop cursor's step: auto-step goes off and no later phase runs. A running hook finishes. Returns whether the driver must cancel the effect in flight.

    Session.close_cursor¶

    def close_cursor(self, cursor: int) -> None

    Close a cursor at rest (Busy otherwise): the driver aborts and waits first.

    Session.open¶

    def open(self, at: int, by: Author, now: int) -> int

    Open a new cursor at node at and wake it. Returns its id. NoSuchNode if at is absent.

    Session.add_item¶

    def add_item(self, to: int, data: ItemData) -> int

    Add an item to cursor to's scratchpad and wake it. Returns the item's id.

    Session.remove_item¶

    def remove_item(self, id: int) -> None

    Remove an item from the scratchpad. NoSuchItem if it is not there.

    Session.append¶

    def append(
    self,
    parent: int,
    body: Body,
    by: Author,
    now: int,
    copied_from: int | None = None,
    derived_from: int | None = None,
) -> int

    Append a node under parent without moving any cursor. copied_from names the node it repeats verbatim, derived_from the node whose walk its content was computed from; NoSuchNode if either is not a node.

    Session.append_root¶

    def append_root(self, config: Config, by: Author, now: int) -> int

    Append a root Config (a detached tree) without moving any cursor.

    Session.set_label¶

    def set_label(self, label: str, cursor: int) -> None

    Put label on cursor; a label already on another cursor moves. CursorClosed if the cursor is closed.

    Session.remove_label¶

    def remove_label(self, label: str) -> None

    Remove label. NoSuchLabel if it is not set.

    Session.hook_move¶

    def hook_move(self, cursor: int, to: int, by: Author, now: int) -> None

    A cursor hook's move of its own cursor to node to. NotInHook unless a cursor hook job is out for cursor.

    Session.hook_write¶

    def hook_write(
    self,
    cursor: int,
    body: Body,
    delivers: Sequence[int],
    by: Author,
    now: int,
    copied_from: int | None = None,
    derived_from: int | None = None,
) -> int

    A cursor hook's write: append a node under the cursor's node, move onto it and consume the delivers items. Returns the new node's id. NotInHook unless a cursor hook job is out for cursor; NotPending if an item is not pending for it. copied_from and derived_from as for append.

    Session.hook_set_auto¶

    def hook_set_auto(self, cursor: int, on: bool) -> None

    A cursor hook's change of its own cursor's auto-step. NotInHook unless a cursor hook job is out for cursor.

    Session.next_job¶

    def next_job(self, cursor: int) -> Job

    The cursor's next job; Job.Rest when it has no step.

    Session.answer¶

    def answer(self, cursor: int, answer: Answer, now: int) -> None

    Session.closed¶

    def cursor(self, cursor: int) -> CursorState

    Session.labels¶

    def labels(self) -> list[tuple[str, int]]

    Session.label¶

    def label(self, label: str) -> int
