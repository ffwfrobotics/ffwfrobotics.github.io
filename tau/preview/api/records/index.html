    The session's records¶

    The values a session is made of, read by every kind of program: nodes and what they hold, who wrote them, the scratchpad's items.

    Names: Author, Body, Config, CursorState, Draft, Item, ItemData, Move, Node, Outcome, Part, Replay, Stop, Tree

    Author¶

    class Author

    Who wrote a node, or asked for a move. Core only records it; extensions and clients may decide by it (attachments expands only what a Frontend typed).

    Config¶

    class Config

    How a step runs from this node on: the text of a JSON object with at most two keys, "model" and "extensions" (the options). The constructor does not check the text, and core stores it without reading it.

    Config.new¶

    def __new__(cls, data: str) -> Config

    Config.data¶

    property data: str

    The JSON object text, as given.

    CursorState¶

    class CursorState

    One cursor as Session.cursor read it: every field from the same instant, under one lock, so busy and at cannot disagree. Later changes do not reach it. Building one costs the cursor's items and labels, not its moves: a move list is append-only, so the snapshot keeps where it ended and reads moves (under the lock, raising Closed if the session is closed) when asked. A move made after the snapshot is not in it.

    CursorState.at¶

    property at: int

    The node the cursor is on.

    CursorState.auto¶

    property auto: bool

    Whether auto-step is on.

    CursorState.busy¶

    property busy: bool

    A step is running.

    CursorState.next¶

    property next: Next

    What the cursor needs next, read from its walk alone.

    CursorState.items¶

    property items: list[Item]

    Its scratchpad, oldest first.

    CursorState.labels¶

    property labels: list[str]

    Its labels, in string order.

    CursorState.moves¶

    property moves: list[Move]

    Every move of the cursor, oldest first.

    CursorState.moves_since_step¶

    property moves_since_step: list[Move]

    Its moves since the running step woke, other hooks' included; none at rest.

    Node¶

    class Node

    One record of a session's tree, written once and never changed: its id, its parent (None for a root), the time the driver gave it in milliseconds, who wrote it (by), what it holds (body), the scratchpad items it consumed (delivers), and where its content came from (copied_from, derived_from), and what a person typed (typed).

    Node.id¶

    property id: int

    The node's id; ids are dense from 0.

    Node.parent¶

    property parent: int | None

    The node it follows, or None for a root.

    Node.time¶

    property time: int

    The time the driver gave it, in milliseconds.

    Node.by¶

    property by: Author

    Who wrote it.

    Node.body¶

    property body: Body

    What it holds.

    Node.delivers¶

    property delivers: list[int]

    The ids of the scratchpad items it consumed.

    Node.copied_from¶

    property copied_from: int | None

    The node this one repeats verbatim (a compaction or prune copy), or None.

    Node.derived_from¶

    property derived_from: int | None

    The node whose walk this one's content was computed from (a summary, a pruned transcript), or None.

    Node.typed¶

    property typed: str | None

    What a person typed, when a hook changed the text of this User node (an attachment inlined a file); None when the body is what was typed.

    Part.Call¶

    class Call(Part)

    A request to run one tool. A call is never a node of its own.

    Replay¶

    class Replay

    Data only the provider that wrote a part can send back (a thinking signature, for one). provider names that provider; data is the text of a JSON object, kept exactly as given. Construction raises BadReplay for an empty or blank provider name, or data that is not a strict JSON object, so a Part never holds a bad one.

    Replay.new¶

    def __new__(cls, provider: str, data: str) -> Replay

    Replay.provider¶

    property provider: str

    The name of the provider that wrote the part.

    Replay.data¶

    property data: str

    The text of the JSON object, exactly as the provider gave it.

    Stop¶

    class Stop
    End: ClassVar[Stop]
    Tools: ClassVar[Stop]
    Length: ClassVar[Stop]
    Interrupted: ClassVar[Stop]
    Error: ClassVar[Stop]

    Why a reply ended. Only Tools makes its calls runnable. It is not an integer: Stop.Tools != 1.

    Tree¶

    class Tree

    The session's nodes: Session.tree. It shares the session's lock, so a read is as current as the call that made it, and a closed session raises Closed here too.

    Tree.node¶

    def node(self, id: int) -> Node

    The node with this id. NoSuchNode if there is none.

    Tree.walk¶

    def walk(self, node: int) -> list[Node]

    The nodes root to node, inclusive.

    Tree.children¶

    def children(self, node: int) -> list[int]

    The children of node, in append order.

    Tree.len¶

    def __len__(self) -> int

    Tree.config_at¶

    def config_at(self, node: int) -> Config

    The Config in force at node: the nearest one on its walk. NoSuchNode if absent.

    Tree.lca¶

    def lca(self, a: int, b: int) -> int | None

    The deepest node on both walks; None across trees.
