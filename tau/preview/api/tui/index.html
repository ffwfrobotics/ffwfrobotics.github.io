    The terminal UI¶

    tau.tui: the Textual app tau opens, which a program can embed or drive, and the picture of the session it draws from.

    Names: tui.FormingCall, tui.Holder, tui.LiveLayer, tui.SessionPicker, tui.SessionView, tui.Switch, tui.TauApp, tui.TauDialog

    tau.tui.FormingCall¶

    @dataclass
class FormingCall
    id: str
    tool: str
    args: str = ''

    A call the model is still writing: its provider id, the tool and the args text so far (args_raw once it is a node).

    tau.tui.Holder¶

    @dataclass(frozen=True)
class Holder
    state: str
    detail: str = ''

    Who has a session, as the picker shows it: a state (served: a live tau serve, which opening attaches to; current: this very session; in use: another process holds its lease; no reply: a serve record whose server did not answer hello) and the detail that says more.

    tau.tui.Holder.pickable¶

    property pickable: bool

    Whether opening it can work: not a session in use, nor one whose server is silent.

    tau.tui.LiveLayer¶

    @dataclass
class LiveLayer
    at: int | None = None
    text: str = ''
    thinking: str = ''
    calls: dict[int, FormingCall] = field(default_factory=lambda: {})
    progress: dict[tuple[int, str], str] = field(default_factory=lambda: {})
    retrying: Retrying | None = None

    What a watched cursor's sample has said and the tree does not hold yet: the reply's text and thinking so far, the calls forming (by their index in the reply), and each running call's progress output keyed by (node, call_id). retrying is the Retrying the provider last said, until the sample says anything else or ends. at is the cursor's node when the first delta arrived: the layer is drawn over it.

    Whether there is nothing to draw.

    tau.tui.SessionPicker¶

    class SessionPicker(TauDialog[SessionInfo | None])
    AGE_WIDTH = 5
    STATE_WIDTH = 6
    CWD_WIDTH = 26
    MIN_TITLE_WIDTH = 20
    scope: reactive[Literal['here', 'all']] = reactive('here', init=False)
    filter_text: reactive[str] = reactive('', init=False)

    Pick a saved session, newest first. rows are tau.list_sessions of the sessions directory (all of them); here is the working directory the "this directory" scope keeps (rows with an error are always listed); held says who holds some of the sessions, by id (session_holders): served, current, in use, no reply. Tab toggles this directory and all; / filters; Enter picks; Esc leaves the filter, then cancels. Dismissed with the row, or None. A row with an error, one in use or one whose server does not answer cannot be picked: the status line says why. The current session can be (it dismisses with its row; the caller does nothing).

    tau.tui.TauApp¶

    class TauApp(App[None])
    CSS_PATH = 'tau.tcss'
    COMMANDS: ClassVar[set[type[Provider] | Callable[[], type[Provider]]]] = {TauCommands}
    BINDINGS: ClassVar[list[BindingType]] = [Binding('escape', 'abort', 'Abort', show=False), Binding('ctrl+c', 'interrupt', 'Abort / quit', show=False, priority=True), Binding('ctrl+q', 'quit', 'Quit', show=False, priority=True), Binding('ctrl+r', "fold('thinking')", 'Fold thinking', show=False), Binding('ctrl+t', "fold('tools')", 'Fold tool boxes', show=False), Binding('alt+left', "move('previous')", 'Previous cursor', show=False), Binding('alt+right', "move('next')", 'Next cursor', show=False), Binding('ctrl+g', "move('tree')", 'The tree', show=False), Binding('ctrl+o', "move('sessions')", 'Sessions', show=False), Binding('ctrl+n', "move('new')", 'New session', show=False), Binding('ctrl+up', "scroll('up')", 'Scroll up', show=False), Binding('ctrl+down', "scroll('down')", 'Scroll down', show=False)]

    The terminal UI of one session, over client, viewing cursor.

    welcome is the server's (or the local start's) answer: the session id and working directory the header shows (None for a session kept in memory, whose header shows cwd, the directory it works in). snapshot are the events the client's stream already gave up (Opened.snapshot); a client whose stream has not been read needs none. theme names one of the themes (None: the default); user themes are read from home, which is TAU_HOME. reconnect, for a remote client, makes a new client with the same id; without it a stream that ends in ConnectionError ends the app's session: the failure is shown, the transcript stays readable and return_code is 1 once the person quits.

    The keys: Enter sends, Ctrl+J starts a new line, Tab completes, Esc aborts the cursor's step (or declines the question the keyboard is in), Ctrl+C aborts if busy, else clears the draft, else quits when pressed twice, Ctrl+R folds the thinking and Ctrl+T the tool boxes, Ctrl+Q quits. / starts a command; one missing arguments opens a form for them.

    tau.tui.TauDialog¶

    class TauDialog(ModalScreen[_T])
    DIALOG_ID: ClassVar[str] = 'tau-dialog'
    TITLE_TEXT: ClassVar[str] = ''
    CANCEL_VALUE: ClassVar[Any] = None
    BODY_ID: ClassVar[str | None] = None
    BINDINGS: ClassVar[list[BindingType]] = [Binding('escape', 'cancel', 'Cancel', show=False)]

    A centred modal with a title, a body, and escape meaning cancel.

    Subclasses supply :meth:compose_body and, usually, :attr:TITLE_TEXT. What they do NOT supply is the shell, the centering, the title styling or the cancel binding — those are the things every dialog agreed on by accident before, and the things a new dialog now gets without asking.

    Attributes: DIALOG_ID: The shell's widget id. Carries the two properties that genuinely differ between dialogs (width, height); everything else comes from the tau-dialog class. TITLE_TEXT: The title, for a dialog whose title never varies. A dialog whose title is supplied per instance passes it to __init__ instead. CANCEL_VALUE: What escape dismisses with. None for a dialog returning an optional value, False for a confirmation — a cancelled question is never a hidden yes. BODY_ID: Set it to give the dialog a scrolling body with that id between a header (the title plus :meth:compose_header) and a footer (:meth:compose_footer), both pinned, so the buttons stay on screen however long the body is . None keeps the plain stack.
