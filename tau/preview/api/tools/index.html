    Tools¶

    What the model can call. Write a Tool, or use the six base tools.

    Names: BashTool, EditTool, FindTool, GrepTool, Progress, ReadTool, Tool, ToolError, WriteTool, base_tools

    BashTool¶

    class BashTool

    bash: a shell command with a timeout. Keeps the tail of long output.

    timeout_ms is the timeout of a call that gives none, max_timeout_ms the most a call may ask for (more is an Err), kill_grace_ms the time between SIGTERM and SIGKILL. Cancelling call terminates the command's whole process group and waits for it to end before the CancelledError propagates, however often it is cancelled meanwhile: no child is left running. Each call has a thread of its own.

    BashTool.call¶

    async def call(self, args_raw: str, *, progress: Progress | None = None) -> Outcome

    Run the command. With progress, the output also goes to it as it arrives: at most one call per 100 ms, carrying all the text since the last, from a thread of the engine's own. The answer is the same either way. The command never waits on progress: a slow one loses the oldest output it has not yet been given (the answer keeps its 10 kB and the overflow file all of it). The answer does wait for a progress call already running and for the final flush, one more call, so a slow progress delays the answer by that much. Calls stop for good when the interpreter begins to exit.

    Progress¶

    Progress = Callable[[str], None]

    A running tool's way to show partial output: progress(text) with the new output since the last call. Safe to call from any thread. Once the tool's call is over (it returned, was aborted, or was cancelled) calling it does nothing.

    Tool¶

    class Tool(Protocol)

    What the driver and providers depend on. A plain function is described as one (tau._tools); any object with these attributes works too.

    Any object with these attributes works, whatever it is written in. The tool owns argument validation: it gets the call's raw JSON text.

    A tool that shows partial output as it runs opts in by giving call a parameter named progress (call(self, args_raw, *, progress=None); the None default keeps the tool a Tool and callable without a driver), detected once when the driver is built. The driver then passes a Progress by keyword. A tool whose call has no such parameter is called with args_raw alone, as before.

    Tool.name¶

    property name: str

    The name the model calls the tool by; unique among a driver's tools.

    Tool.description¶

    What the tool does, as the model reads it.

    Tool.parameters¶

    property parameters: Mapping[str, object]

    A JSON Schema object describing the arguments.

    Tool.call¶

    async def call(self, args_raw: str) -> Outcome

    Run with the call's args_raw. Answer Ok or Err; an exception raised is the call's Err(str(e)).

    ToolError¶

    class ToolError(Exception)

    Why a call failed; the call answers it as Err(message), exactly that text. A tool function may raise it to say something to the model without a type prefix.
